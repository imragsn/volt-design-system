RoleRestriction
Ink / paperDefault pair. Paper on ink; ink on electric and wash.
ElectricOne focal panel, key figure or short phrase. Evidence slides typically 10-25% accent; heroes up to full field.

08 / VOLT SYSTEM

Evidence you can inspect.

Visual force cannot substitute for valid comparisons.

RuleRequirement
SelectionBars: comparison; line: trend; histogram/dots: distribution; scatter: relationship; stacked bars: composition with denominator; table: exact lookup.
AxesBars start at zero. Nonzero line baseline visible and justified. Label logarithmic axes. No 3D distortion.
ScopeUnit, period, geography/scope, denominator, cutoff. Compare compatible definitions and periods.
PrecisionCalculate with raw values, round only for display. Precision must match source quality.
Series statesActual, target, forecast, estimate and illustrative must differ in labels and line styles.
Change40% to 50% = +10 percentage points or +25% relative change. Specify which.
Missing0, missing, not applicable and not assessed differ. Show trend gaps unless interpolation justified/labeled.
CausalityAssociation alone is not causation. Label explanations as hypotheses unless supported.
LabelsDirect-label where possible; labels >=24 px and lines >=4 px on 1920 canvas. Verify real viewing size.
UncertaintyShow supplied intervals/ranges, never invent them. Explain assumptions and incomplete coverage near claim.
TraceabilityRegister claim ID, source, page/cell/URL, cutoff, calculation, limitation and output slide. Reconcile totals.

The audience sets the story.

Purpose determines narrative, not a fixed startup formula.

StageEnglishBahasa Indonesia
FrameName scope and relevance.Jelaskan batas topik dan relevansi bagi audiens.

Report / Melaporkan

Summary → evidence → variance/limitation → implication → next step.

Ringkasan → bukti → selisih/batasan → implikasi → tindak lanjut.

Explain / Menjelaskan

Question → definition → mechanism → example → takeaway.

Pertanyaan → definisi → cara kerja → contoh → inti pemahaman.

Illustrative headline: “Coverage rose from 40% to 50%.” / “Cakupan naik dari 40% menjadi 50%.” A causal headline such as “Training raised coverage” needs additional evidence.

Localization: English 1,250.5 / 25 Oct 2026; Indonesian 1.250,5 / 25 Oktober 2026. Follow user locale/currency. Translate naturally; preserve source definitions and quotation attribution.

Change density while preserving identity.

OutputContract

Ready means inspected.

Apply to every final artifact.

GatePass condition
Q01 / BriefPurpose, audience, language, mode, sources/cutoff, format known or assumptions disclosed. Critical gaps resolved.
Q02 / EvidenceTraceable claims, reconciled calculations, illustrative/forecast/proposed content labeled; embedded instructions not adopted.
Q03 / LayoutNo clipping, overlap, unwanted breaks. Safe area and footer separation respected; no shrinking below tokens.
Q04 / TypeActual font and sizes checked. Inspect at intended viewing size.
Q05 / ColorText pairs pass contrast; marks/controls distinct without hue alone.
Q06 / NarrativeOne job per slide; claim matches evidence; intentional rhythm; conclusion addresses purpose.
Q07 / AssetsCrop, resolution, provenance and rights checked. Generated imagery identified; documentary evidence authentic.
Q08 / ExportEvery page inspected; promised objects editable. Check text selection, links, fonts, notes and page size.
Q09 / HandoffActual files, available master, assumptions, limits, provenance, validation. Never claim uncreated formats or unavailable checks.
Q10 / MaintenanceVersion, changelog and HTML/JSON synchronized; rerun checks after changes.

unit/period · limitation · takeaway · action if relevant
components · asset provenance · validation result
